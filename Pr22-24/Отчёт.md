# Отчёт по практическим занятиям №19–23
## Практическое занятие №19
1) Реализовано простое API для управления пользователями с использованием Node.js и PostgreSQL.
2) Созданы эндпоинты для создания, чтения, обновления и удаления пользователей. Данные хранятся в реляционной таблице.
3) Получены знания о плюсах реляционной базы данных и о структуре её работы.

## Практическое занятие №20
1) Разработано аналогичное API для пользователей, но с использованием MongoDB и Mongoose.
2) Применена документо-ориентированная модель, реализованы все CRUD-операции, демонстрирующие отличие NoSQL-подхода от реляционного.
3) Получены знания о NoSQL базах данных, о подходе к их созданию и их работе.

## Практическое занятие №21
1) К существующему RBAC-приложению добавлено кэширование для маршрутов чтения (/api/users, /api/users/:id, /api/products, /api/products/:id).
2) Настроены TTL, реализована инвалидация кэша при изменении данных.
3) В проекте использовался Redis ввиду своей быстрой работы и эффективности при работе с хэшем.

## Практическое занятие №22

1) Создана тестовая система с двумя и более backend-серверами (Node.js), настроен Nginx в качестве балансировщика с алгоритмом round-robin.
2) Добавлены параметры отказоустойчивости (max_fails, fail_timeout), а также альтернативная конфигурация для HAProxy.
3) Пока работают первые два сервера, запросы не поступают на резервный. Он заработает только в случае отказа первых двух.

## Практическое занятие №23
1) В среде WSL установлен Docker и Docker Compose.
2) Развёрнуто микросервисное приложение (API Gateway, сервисы users и orders) из примера, а также собственное приложение с балансировкой через Nginx и несколькими backend-контейнерами.
3) Проверена работа circuit breaker, томов и сетей Docker.
4) Получены знания об устройстве Docker и принципе его работы.
